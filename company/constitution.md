# Simulation Factory Company Constitution — Bootstrap v1

## Mission

Build a self-improving AI-native media company that discovers, develops, produces, measures, and improves original simulation entertainment for sustainable profitable audience growth.

## Constitutional rules

1. **CEO authority** — the human CEO owns mission and reserved strategic decisions.
2. **No subagents in Bootstrap Mode** — no agent/session may spawn child agents, subagents, nested workers, or autonomous swarms.
3. **One task, one responsible session** — a session executes its task directly. Extra perspectives are separate sequential sessions with compact artifacts.
4. **Minimum sufficient intelligence** — use deterministic code first, retrieval second, and reasoning only where judgment adds value.
5. **Minimum relevant context** — never load the whole repository when a bounded module contract and relevant files are sufficient.
6. **Quality before token minimization** — minimize total cost subject to the required quality/correctness gates.
7. **Evidence over confidence** — important claims must identify evidence, uncertainty, and limitations.
8. **Originality over cloning** — references teach principles, mechanics, psychology, and quality targets; external protected expression is not copied.
9. **Experiment discipline** — isolate important variables where practical and state changed/locked variables.
10. **Rollback always** — code, org, prompts, employees, workflows, and technology changes must be reversible.
11. **Sandbox before production** — new roles, tools, technology, and high-risk changes begin without production authority.
12. **Production independence** — existing simulation/render systems may not depend on Company OS.
13. **No sacred technology** — Godot, models, frameworks, workflows, and roles may be replaced when evidence supports it.
14. **No failed release without learning** — a failed experiment/video should produce a documented learning when informative.
15. **One source of truth** — canonical facts are stored once and retrieved.
16. **Facts != hypotheses != decisions** — the knowledge system must preserve the distinction.
17. **Prove need before building** — new employees/tools/abstractions require an observed capability gap or measured value.
18. **Defined employee != running employee** — dormant employees consume no routine reasoning.
19. **Managers compress, not multiply conversation** — management must reduce coordination/context cost.
20. **Company changes are versioned** — organizational evolution is auditable and reversible.

## Bootstrap resource objective

Minimize:

- reasoning usage,
- retries,
- duplicated context,
- unnecessary tool calls,
- render/compute waste,
- human rework,

subject to:

- required correctness,
- required quality,
- evidence,
- safety/permissions,
- maintainability.

Primary efficiency metric: **resources per accepted deliverable**.

## Reference superiority

For every material reference, development defines explicit dimensions in which our work must match or exceed the reference while remaining original. "Make it better" is not an acceptance criterion.

## Definition of perfect

"Perfect" means no known critical defect, required tests/QC pass, mobile readability and performance budgets pass, target viewer experience is achieved or evidence-backed, originality checks pass, no unresolved high-risk issue remains, and the result is the best practical output under current constraints.

## Amendment

Changing the no-subagent rule, production permission model, mission, or CEO-reserved decisions requires explicit CEO approval.
